# weave — intent compiler for layer composition (replaces construct/setup.sh)

## Problem

`construct/setup.sh` began as a run-once repo bootstrapper and has grown into the de-facto compiler that wires every ariadne-derived repo's agentic context. Three problems:

1. **Wrong altitude.** It's a bash interpreter of *file-ops* (`symlink X Y`) when what we want is a compiler of *intents* (`prose`, `skill`, `settings`, …). Structured composition — DAG resolution, JSON merge, multi-target codegen — strains bash, already evidenced by the separate `merge-settings.sh` and the bolted-on `discover-ancestors.test.sh` seam.
2. **Known bugs.** (a) Layer dependencies are partly carried by `go.mod` `replace` — the nous→brain *layer* edge lives in `go.mod`, not `construct/deps` (a constant source of confusion). (b) `@AGENTS.local.md` resolves through the symlinked `AGENTS.md` to *ariadne's* copy, so a downstream repo's own local prose never loads — every repo silently inherits ariadne's "you're in ariadne" note.
3. **Misleading name.** "setup" implies run-once; it's idempotent and should run on every layer/prose change.
