## Lessons learned
- A *required deterministic step* placed in a natural-language prompt for the agent to run (`COMPACT_PROMPT` step 2 = "then run `pair continue`") is **not** deterministic — the agent can skip it, and did (the "restart stopped working" bug). Move such steps into code; the prompt should carry only judgment work (writing the continuation), never mechanism. General pattern for any "automatic X" feature.
- When code and its tracker live in different repos, move the issue to the code's repo — keeps the close-review, code, and history together and makes the SDLC close/window math correct.
