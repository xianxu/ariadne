## Lessons learned

- Cross-repo mutation needs two independent safety decisions: whether the
  semantic update should happen, and whether Git state authorizes an automatic
  commit. Conflating them would either block valid issue closes or commit into
  someone else's branch.
- Terminal project migration should respect the vocabulary lifecycle and
  archive layout; relocating a completed record into a live portfolio would
  manufacture false current work.
- A missing peer checkout is meaningful design evidence, not merely an
  environment error. Charon's absence exposed that artifact residency should
  follow current product ownership rather than a historical repo name.
