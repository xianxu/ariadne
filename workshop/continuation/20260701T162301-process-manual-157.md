- **Judge prompts → `judge/prompts/*.md`, NOT `helptext/`** — helptext's `//go:embed *.md`
  would mis-file them into the manual's Help-text section. Byte-fidelity locked by a golden
  captured *pre-refactor* (never re-capture).
- **Body = gist default + `--full`** (not full-inline). Fencing heading-bearing bodies
  decouples body verbosity from the markdown *outline* — the outline (the "first-level
  abstraction" the user valued) is byte-identical gist vs `--full`.

  refused with `--out`.
- **Dynamic reconstruction: Go-native, not shell-to-Python** — must match M1's in-process Go
  catalog (ARCH-DRY).

  each embed the single-source registry), NOT injected redundancy — each judge runs in its own
  fresh subprocess.

## Lessons learned
- **SDLC multi-milestone ship-flow** — see the pensive. `milestone-close` (reviewed) vs
  `close --milestone` (no-judge escape); `--no-verdict` for review-together milestones; the
  merge conformance/specs gates validate the whole branch diff; `git push origin HEAD`
  explicitly (bare push silently no-op'd once).
- **Byte-fidelity refactors:** golden-capture the *pre-refactor* output first, commit, then
  refactor — never re-capture. It made prompts→markdown provably safe.
- **The manual validates its own thesis:** the value is the *outline* (a navigable index of
  every injection point), not the full dump — that's what makes "occasionally understand the
  process" real for a human.
