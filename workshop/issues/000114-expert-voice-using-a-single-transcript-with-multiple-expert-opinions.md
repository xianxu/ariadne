# expert voice: using a single transcript with multiple expert opinions

the way I use ariadne, is as my workbench. Such workbench brings in the power of AI, in terms of world knowledge and the ability to manage process on behalf of a human operator.

Oftentimes, when we pull in world's knowledge, it helps to limit the agent to be arguing from a particular view point, which essentially for them to "pretend" to be an expert of a particular persuasion. Ideally, I'd love to name a team of expert: David the architect, Matt the historian (knows the codebase), Pritika (the PM). those persona should be accessible from all aspects of ariadne.

One particular interesting aspect of such interaction would be in the chat session itself, you can ask David to answer some part of things, e.g. David, would this be problematic when we integrate with X in the future?

Now, it's cool, and theoretically might be useful, in practice I'm not sure if asking David the question would yield different answer from asking just the main agent itself. 

Another aspect of those expert, you can always invoke subagent to run something, and there I think some "focus" orientation that's similar to this expert framing might make more sense.
