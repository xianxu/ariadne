# How does the rename interact with files that already name a mode?

_From [What should the modes be called?](01-naming.md), section "What should the modes be called?"._

No file names a mode yet: the key is new, so there is nothing to migrate. A file written with a draft name would
fail its round as an unknown mode, and the reply lists the three names.
